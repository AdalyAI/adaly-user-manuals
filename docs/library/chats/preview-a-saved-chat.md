# Preview a Saved Chat

1\. Hover over the plus icon to open the navigation menu

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/06d59f2f-4e3a-4702-b7ed-e1c2a55abe6e/ascreenshot.jpeg?tl_px=0,153&br_px=2248,1410&force_format=jpeg&q=100&width=1120.0)


2\. Click the Library icon.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/06d59f2f-4e3a-4702-b7ed-e1c2a55abe6e/ascreenshot.jpeg?tl_px=0,0&br_px=2248,1256&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=8,124)

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/6344acd0-bac3-4487-b9fd-088739d4b211/ascreenshot.jpeg?tl_px=0,56&br_px=2248,1313&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=533,277)
