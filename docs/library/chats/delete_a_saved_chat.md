# Delete a Saved Chat

1\. Hover over the plus icon to open the navigation menu

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/7c301964-89d7-4181-b7ed-9a147b948c81/ascreenshot.jpeg?tl_px=0,153&br_px=2248,1410&force_format=jpeg&q=100&width=1120.0)


2\. Click the Library icon.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/7c301964-89d7-4181-b7ed-9a147b948c81/ascreenshot.jpeg?tl_px=0,0&br_px=2248,1256&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=6,117)

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/f0c69c38-6e2b-40ba-82a5-32dc9ddb85d7/ascreenshot.jpeg?tl_px=0,54&br_px=2248,1311&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=736,277)
