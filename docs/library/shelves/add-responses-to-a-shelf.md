# Add Responses to a Shelf


1\. Hover over the plus icon to open the navigation menu

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/a7ec681d-d223-4663-a18e-7c96dd8d66d0/ascreenshot.jpeg?tl_px=0,153&br_px=2248,1410&force_format=jpeg&q=100&width=1120.0)


2\. Click the Library icon.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/a7ec681d-d223-4663-a18e-7c96dd8d66d0/ascreenshot.jpeg?tl_px=0,0&br_px=2248,1256&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=0,115)


3\. Click on the Saved Chat with the response you want to add.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/486e17ff-2198-4c65-ba84-3bc97acff584/ascreenshot.jpeg?tl_px=0,96&br_px=2248,1353&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=682,277)


4\. Click on the Connector with the response you'd like to add to the Shelf.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/68fe660b-532a-466a-9f31-1a93ad0b9034/ascreenshot.jpeg?tl_px=0,0&br_px=2248,1256&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=55,205)


5\. Click this icon.

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/9fc02782-0630-4360-9d65-0428f22456e3/ascreenshot.jpeg?tl_px=0,0&br_px=2248,1256&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=553,76)
