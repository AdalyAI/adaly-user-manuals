# Upload a Web Page to a Brand

1\. Hover over the plus icon to open the navigation menu

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/c52ef58c-0a08-4f17-b310-54db8ad1a9a4/ascreenshot.jpeg?tl_px=0,153&br_px=2248,1410&force_format=jpeg&q=100&width=1120.0)

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/c52ef58c-0a08-4f17-b310-54db8ad1a9a4/ascreenshot.jpeg?tl_px=0,0&br_px=2248,1256&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=-1,242)

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/4b90d44d-c42c-4e9f-9926-4b05f1d1dcc2/ascreenshot.jpeg?tl_px=0,307&br_px=2248,1564&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=145,355)

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/5952e704-4905-4eea-b4c7-54c120966b8f/ascreenshot.jpeg?tl_px=0,0&br_px=2248,1256&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=952,254)

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/ea4dbdcc-43ea-416e-80ad-965d5e77758b/ascreenshot.jpeg?tl_px=0,0&br_px=2248,1256&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=858,250)

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/6f31dd5a-d4a5-45b2-9f44-6c791e977c80/ascreenshot.jpeg?tl_px=0,0&br_px=2248,1256&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=599,208)

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/2c66b562-cba2-4e45-978f-a4828be770a8/ascreenshot.jpeg?tl_px=0,0&br_px=2248,1564&force_format=jpeg&q=100&width=1120.0)
