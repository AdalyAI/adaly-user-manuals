# Upload a File

1\. Hover over the plus icon to open the navigation menu

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/ded2a12b-41db-413a-8128-e9a7bcc0213a/ascreenshot.jpeg?tl_px=0,153&br_px=2248,1410&force_format=jpeg&q=100&width=1120.0)

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/ded2a12b-41db-413a-8128-e9a7bcc0213a/ascreenshot.jpeg?tl_px=0,0&br_px=2248,1256&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=-8,236)

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/66b64d1a-0929-4d68-a288-178b36c9057c/ascreenshot.jpeg?tl_px=0,0&br_px=2248,1256&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=956,236)

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/a5f42d09-9ac9-4628-a5df-1e9eda1cf268/ascreenshot.jpeg?tl_px=0,0&br_px=2248,1256&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=817,206)

![](https://ajeuwbhvhr.cloudimg.io/https://colony-recorder.s3.amazonaws.com/files/2025-10-15/bb9c6093-fb3e-4737-837b-03d1f4a189be/ascreenshot.jpeg?tl_px=0,0&br_px=2248,1256&force_format=jpeg&q=100&width=1120.0&wat=1&wat_opacity=0.7&wat_gravity=northwest&wat_url=https://colony-recorder.s3.us-west-1.amazonaws.com/images/watermarks/FB923C_standard.png&wat_pad=606,220)
